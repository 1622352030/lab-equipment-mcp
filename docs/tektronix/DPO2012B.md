# Tektronix DPO2012B 使用说明

本页已根据 `DPO2000编程手册.pdf`（MSO2000B/DPO2000B/DPO2000 系列 Programmer Manual，
文档号 077-0738-00）复核，重点覆盖接口、SCPI 语法、即时测量和波形传输章节。

[返回项目中文首页](../../README.md)

本文说明如何在 Windows 上通过 USB Type-B 数据线连接 Tektronix（泰克）
DPO2012B 示波器，并使用本项目提供的 `lab-equipment` MCP 进行识别、测量和
波形读取。

## 通信方式

DPO2012B 机身后部的 USB Type-B 端口是 USB 2.0 设备端口，通过 USBTMC
协议与电脑通信。上位机使用 VISA 资源访问示波器，而不是将示波器当作串口
COM 设备。

本项目当前为 DPO2012B 声明并实测的接口是 **USBTMC/VISA**。编程手册还说明：安装
可选 **DPO2CONN Connectivity Module** 后可使用 Ethernet/VXI-11；通过
**TEK-USB-488 Adapter** 可从后部 USB 设备口桥接 GPIB。LAN/GPIB 已在驱动中建模，
但尚未进行真实硬件验收。

正常识别后的 VISA 地址类似：

```text
USB0::0x0699::0x039D::<设备序列号>::INSTR
```

其中：

- `0x0699` 是 Tektronix 的 USB 厂商 ID。
- `0x039D` 是本项目实测 DPO2012B 的 USB 产品 ID。
- `<设备序列号>` 会因示波器而异。

编程手册确认 DPO2012B 的 USB 参数为 Tektronix VID `0x0699`、产品 ID `0x39D`，接口描述
为 `USBTMC-USB488`。产品 ID 和接口类型是型号级公开信息，不包含具体设备序列号。

## NI-VISA 驱动

本项目实机测试可使用以下 NI 官方驱动：

- **NI-VISA 15.0 Runtime**
- 官方下载页面：<https://www.ni.com/zh-cn/support/downloads/drivers/download/unpackaged.ni-visa.306106.html>
- 可用性记录日期：**2026-07-20**

> 截至 2026-07-20，NI 官方页面提供的 NI-VISA 15.0 Runtime 可用于本项目
> DPO2012B 的 USBTMC/VISA 通信环境。本项目已通过真实 DPO2012B 完成设备
> 识别、SCPI 身份查询、频率/RMS 测量和波形读取。由于该驱动版本较旧，在
> 其他 Windows 版本或不同系统配置中使用时，仍建议先确认 NI 官方页面列出的
> 系统要求。

安装完成后，请执行以下操作：

1. 关闭并重新打开示波器，或重新插拔 USB 数据线。
2. 打开 Windows 设备管理器。
3. 确认设备不再显示黄色感叹号或错误代码 28。
4. 设备通常会显示为 `USB Test and Measurement Device (IVI)`。

## 硬件连接

1. 打开 DPO2012B 电源。
2. 使用支持数据传输的 USB Type-B 转 USB Type-A 数据线。
3. Type-B 端连接示波器后部的 USB Device 端口。
4. Type-A 端连接电脑 USB 端口。
5. 在示波器 `Utility` / `I/O` 菜单中确认 USB Computer 功能可用。

注意不要将前面板用于 U 盘的 USB Host 端口误认为电脑控制端口。

## 安装 MCP

先确保已经安装 Codex 和 `uv`，然后在 PowerShell 中运行：

```powershell
irm https://raw.githubusercontent.com/1622352030/lab-equipment-mcp/main/scripts/install-codex.ps1 | iex
```

安装完成后，需要完全退出 Codex Desktop，重新打开并创建一个新任务。

## 检查设备

在 Codex 新任务中输入：

```text
调用 lab-equipment 的 dpo2012b_diagnose_setup，告诉我 ready 是否为 true。
```

正常情况下，返回结果应包含：

```text
ready: true
USB0::0x0699::0x039D::<设备序列号>::INSTR
```

也可以要求 MCP 列出 VISA 资源：

```text
调用 lab-equipment 的 list_visa_instruments，列出并识别当前 VISA 仪器。
```

## 常用操作

读取设备身份：

```text
连接 DPO2012B，然后读取设备身份信息。
```

测量 CH1：

```text
连接 DPO2012B，读取 CH1 当前频率和 RMS。
```

获取波形：

```text
连接 DPO2012B，获取 CH1 的 1000 个波形点。
```

## 已验证功能

截至 2026-07-26，本项目已在真实 DPO2012B 上验证：

- Windows USBTMC/IVI 设备枚举
- VISA 资源扫描
- `*IDN?` 设备身份查询
- CH1/CH2 垂直设置读取
- 编程手册列出的全部 MCP 即时测量类型，使用 SDG1062X CH1/CH2 完成双通道闭环
- 波形前导参数读取
- ASCII、FASTest、RIBinary、RPBinary、SRIBinary、SRPBinary 原始波形读取与时间/电压缩放；全部二进制编码均验证 1/2 字节宽度
- 通用只读 SCPI 查询、受保护文本写入及写后回读
- `dpo2012b_command` 完整文本 SCPI 入口，覆盖编程手册中适用于 DPO2012B 且未做专用工具的命令
- `dpo2012b_query_binary` 完整二进制块查询并以 Base64 返回
- `dpo2012b_capture_screenshot` 使用 `HARDCopy START` 获取 PNG/BMP/TIFF 屏幕图像，并核对文件签名

编程手册还核对了波形传输顺序：`DATa:SOUrce`、`DATa:ENCdg`、`DATa:WIDth`、
`DATa:STARt`/`DATa:STOP`、`WFMOutpre?`、`CURVe?`。MCP 现在支持 ASCII、RIBinary、
RPBinary、SRIBinary、SRPBinary（以及 FASTest 映射到 RIBinary）的读取，宽度为 1 或 2
字节，并按前导码换算为时间/电压值。编程手册的即时测量枚举也已扩展至幅值、面积、
峰值、占空比、边沿/脉冲计数、过冲、相位等 DPO2012B 支持项。

编程手册中适用于 DPO2012B 的普通文本 SCPI 命令通过 `dpo2012b_command` 覆盖；
`query=true` 只允许查询，`query=false` 只允许设置命令。选件相关命令保留由仪器
根据已安装模块决定是否接受；校准、复位、文件删除、固件/安全等高风险命令默认仍被
安全层拦截。固件 v1.52 的 `HARDCopy START` 实测会直接返回裸 PNG/BMP/TIFF 文件字节，
而非 IEEE 488.2 块；驱动同时兼容裸图像和带块头两种响应。二进制读取期间会临时关闭
VISA 文本读取终止符，防止图像或波形中的 `0x0A` 被误认为消息结束。图像和其他二进制
响应均通过 Base64 工具返回，避免 MCP 文本通道直接传输原始二进制。

2026-07-26 的完整复验通过 47/47 项：SDG1062X CH1 输出 1 kHz、CH2 输出 2 kHz、
两路均为 1 Vpp 正弦波；DPO2012B 测得两路频率、RMS 和峰峰值符合预期。验收还覆盖
全部即时测量枚举、双通道 ASCII/全部二进制波形组合、通用二进制查询和三种截图格式。
验收结束后 SDG1062X 两路输出均关闭，示波器设置恢复，会话断开。此结果验证了 MCP
公开工具和波形/截图数据路径；通过完整 SCPI 入口覆盖但未逐条实机调用的低频或选件命令，
不能据此标记为逐条硬件验证。LAN VXI-11 和 GPIB 仍为已实现、未实机验证。

实测设备身份格式：

```text
TEKTRONIX,DPO2012B,<设备序列号>,<固件信息>
```

文档、日志和问题报告不得公开真实序列号、USB 实例 ID 或完整未脱敏的 `*IDN?` 响应；
VISA 地址和身份示例均使用占位符。

## 常见问题

### 设备出现在“其他设备”，并带黄色感叹号

这通常表示 USB 连接已经建立，但 VISA/USBTMC 驱动尚未正确安装。安装
NI-VISA Runtime 后重新插拔设备，再检查设备管理器。

### Windows 显示错误代码 28

错误代码 28 表示设备驱动未安装。请安装本页列出的 NI-VISA 15.0 Runtime，
然后重新连接示波器。

### `list_visa_instruments` 中没有 DPO2012B

依次检查：

1. 示波器是否开机。
2. USB 线是否支持数据传输。
3. 是否连接了后部 USB Device 端口。
4. 设备管理器中是否正确显示 IVI 测试测量设备。
5. NI-VISA Runtime 是否已安装。
6. 是否有其他测试软件独占了 VISA 会话。

### Codex 中找不到 `lab-equipment` 工具

运行以下命令检查配置：

```powershell
codex mcp get lab-equipment
codex mcp list
```

确认状态为 `enabled` 后，完全退出 Codex Desktop，重新打开并创建新任务。

## 安全说明

本项目还支持 Agilent/Keysight DSO-X 2012A 作为另一种双通道 USBTMC/VISA 接收示波器。
SDG1062X 已分别通过 DPO2012B 和 DSO-X 2012A 完成双通道闭环验收；DPO2012B 本身的
既有验收结果和接口结论不因新增接收设备而改变。

项目默认拦截校准、固件更新、复位、保存/恢复配置和文件删除等高风险 SCPI
命令。普通设备诊断、状态查询、测量和波形读取不需要启用危险命令。
