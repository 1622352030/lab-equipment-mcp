# GW Instek AFG-2125 使用说明

[返回项目中文首页](../../README.md)

本文说明如何在 Windows 上通过 Mini USB-B 数据线连接 GW Instek AFG-2125
任意波形发生器，并使用本项目的 `lab-equipment` MCP 进行识别、参数读取、
波形配置和任意波形下载。

## 手册依据

开发时使用了用户提供的以下本地资料，但没有将受厂商版权约束的 PDF、驱动或
安装包提交到仓库：

- `AFG-2000使用手册.pdf`，适用于 AFG-2000/AFG-2100 系列，手册料号
  `82AFB21200EA1`。
- `ARB软件SOP使用手册.pdf`，AFG 任意波形编辑软件操作说明。

已核对手册的后面板、USB 远程连接、消息终止符、IEEE 488.2/SCPI 命令、
输出设置和任意波形章节。

## 通信方式

AFG-2125 后面板的 **Mini USB-B** 是电脑远程控制端口。物理连接虽然是 USB，
设备实际枚举为 **USB CDC 虚拟串口**，Windows 中显示为 `AFG CDC Device
(COMx)`，VISA 地址为 `ASRLx::INSTR`。它不是 USBTMC 设备。

当前实现和真实设备验收使用：

| 层次 | 配置 |
| --- | --- |
| 物理接口 | 后面板 Mini USB-B 设备端口 |
| Windows 设备 | `AFG CDC Device (COMx)` |
| VISA 资源 | `ASRLx::INSTR` |
| 串口参数 | 19200 baud、8 数据位、无校验、1 停止位、无流控 |
| 终止符 | LF（`\n`） |
| 命令协议 | SCPI 1994 部分兼容、IEEE 488.2 兼容 |

本项目自动发现时会先用 Windows PnP 信息筛选 GW Instek 的
`VID_2184&PID_001C`，只对匹配的 COM 口建立连接，不会向其他串口盲发
`*IDN?`。

## 驱动与软件

以下环境已于 **2026-07-20** 在当前 Windows 电脑和真实 AFG-2125 上验证：

- GW Instek AFG-2000 USB CDC 驱动：`GWinstek usbser 1.01.0`。
- Windows 驱动 INF：`oem168.inf`（仅为当前电脑的安装实例名称）。
- GW Instek AFG 任意波形编辑软件：`AFG 3.0.0`。
- PyVISA 配合已安装的 VISA Runtime，可见 `ASRLx::INSTR`。

驱动和波形编辑软件来自用户已下载的 GW Instek 安装包。本仓库不分发厂商
安装程序。换电脑时，请从 GW Instek 官方支持页面或设备随附资料获取与系统
匹配的 AFG-2000 USB 驱动和 AFG 编辑软件。

如果 MCP 无法打开串口，请先完全退出 AFG 编辑软件、串口调试工具和其他 VISA
程序。同一个 COM 口通常不能被多个程序同时占用。

## 已验证能力

真实设备返回的身份格式如下，文档和日志不得公开实际序列号：

```text
GW INSTEK,AFG-2125,SN:<已隐藏>,V1.11
```

已在真实设备上完成以下验收：

- `*IDN?` 身份查询。
- 当前函数、频率、幅度、DC 偏置、幅度单位和 `APPLy?` 摘要读取。
- VISA 串口参数和 LF/CR/CRLF 查询终止方式验证；项目默认使用 LF。
- 正弦、方波、斜波、噪声和 8 点任意波的 MAIN 输出闭环测量。
- 频率、幅度、偏置、方波占空比、斜波对称性和 MAIN 输出开关。
- AM、FM、FSK、线性 Sweep 的内部源配置、参数回读、互斥状态和关闭状态。
- 8 点任意波的上传、USER/ARB 选择、频率回读、波形速率校验和 SYNC 周期。
- DPO2012B 与 AFG-2125 在同一 MCP 进程中的独立 VISA 会话和同时连接。

2026-07-21 使用 AFG MAIN→DPO2012B CH2、SYNC→CH1 完成调制和扫频闭环：

- AM：10 kHz 载波、20 Hz 正弦调制、50% 深度，CH2 包络峰峰值随调制变化；
  CH1 载波同步约 10 kHz。
- FM：10 kHz 载波、20 Hz 调制、2 kHz 偏差，CH1 测得约 8.01–11.99 kHz。
- FSK：5 kHz 载波、10 kHz 跳频、2 Hz 速率，CH1 在约 5/10 kHz 两档切换。
- Sweep：1–5 kHz、0.5 s、线性立即扫描，CH1 连续采样覆盖约
  1.49–4.89 kHz；起止频率、间隔、触发源和模式状态均完成回读。
- ARB：8 点波形、1 kHz，仪器回读 `ARB`、1 kHz、8 kHz 波形速率；CH1
  按手册所述在每个 ARB 周期输出同步脉冲，连续测得 1 kHz。

上述验收使用内部调制/触发源。外部 AM/FM 的后面板 MOD 输入以及外部
FSK/Sweep 的 TRIG 输入尚未接线验收，因此只能标记为 SCPI 已实现、物理路径未测试。
任意波 MAIN 的自动频率算法会受非正弦形状影响，验收以仪器回读和 SYNC 周期为准。

手册第 107 页将 MAIN 输出命令写为根级 `OUTPut`，但固件 V1.11 实机上的
`OUTPut?`、`OUTPut OFF/ON` 没有可靠响应；`SOURce1:OUTPut?` 和
`SOURce1:OUTPut OFF/ON` 可以稳定读写 MAIN 状态。因此驱动采用实机验证过的
`SOURce1:` 兼容路径，并将它记录为 V1.11 行为，而不是手册通用语法。

## 参数范围

| 功能 | AFG-2125 范围 |
| --- | --- |
| 正弦/方波频率 | 0.1 Hz–25 MHz |
| 斜波频率 | 0.1 Hz–1 MHz |
| 任意波低层频率命令 | 0.1 Hz–10 MHz |
| 幅度（50 Ω） | 1 mVpp–10 Vpp |
| DC 偏置（50 Ω） | -5 V–+5 V，且满足 `abs(offset) + Vpp/2 <= 5 V` |
| 斜波对称性 | 0%–100% |
| 任意波点数 | 2–4096 点 |
| 任意波点值 | 整数 -511–511 |
| 任意波波形速率 | `频率 × 点数`，不超过 20 MHz |
| AM/FM 内部调制频率 | 2 mHz–20 kHz |
| AM 内部调制深度 | 0%–120% |
| FSK 内部速率 | 2 mHz–100 kHz |
| Sweep 时间 | 1 ms–500 s |

方波占空比随频率变化：低于 100 kHz 为 1%–99%，100 kHz 至 5 MHz 为
20%–80%，5 MHz 至 10 MHz 为 40%–60%，10 MHz 及以上只能为 50%。

占空比参数表示方波高电平所占周期的百分比，驱动会将百分比原样发送给
`SOURce1:SQUare:DCYCle`，不会执行 `100 - duty` 取反。2026-07-21 实机面板
设为 80% 后，SCPI 查询返回 80%，DPO2012B 测得 SYNC 正占空比约 80.03%、
MAIN 正占空比约 79.95%，三者一致。此前将 SYNC 占空比描述为 MAIN 的互补值
属于验收判断错误，现已撤回。设置工具会在写入后查询实际值并检查是否一致。

### 固件 V1.11 冷启动后的 SYNC 占空比异常

2026-07-21 在同一台固件 V1.11 设备上连续两次断电重启后稳定复现以下现象：

1. 仪器恢复为 2 kHz 方波、20% 占空比，SCPI 查询
   `SOURce1:SQUare:DCYCle?` 返回 20%，MAIN 默认处于 OFF。
2. 此时 SYNC 仍输出约 2 kHz、5.12 Vpp 的 TTL 信号，但 DPO2012B 测得正脉宽
   约 400 us、负脉宽约 100 us，即高电平约 80%、低电平约 20%。
3. 未重写函数、频率或占空比，仅将 MAIN 从 OFF 切换为 ON，SYNC 立即变为
   正脉宽约 100 us、高电平约 20%，并与 CH2 MAIN 的约 20% 一致。
4. 首次开启 MAIN 完成校正后，再次关闭 MAIN、重新写入 20%/80% 占空比、切换
   正弦/方波或断开并重连 VISA，SYNC 均会正确跟随设置，不再出现互补值。

DPO2012B CH1 的输入反相查询为 OFF，因此该现象不是示波器反相或占空比计算
错误；断开并重连 VISA 也不会触发或修复它，说明它不是 MCP/串口指令问题。
现有证据表明：V1.11 在冷启动恢复方波参数时，没有同步完成 SYNC 极性状态的
初始化；第一次启动 MAIN 波形引擎会重新初始化并锁存正确极性。无法在没有厂商
固件源码的情况下确定具体内部寄存器或 FPGA 状态，因此将其记录为实机可复现的
固件行为，而不是项目驱动的命令转换。

临时规避方法：仪器冷启动后先在确认接线、负载、幅度和偏置安全的前提下开启
一次 MAIN，再使用 SYNC。若不允许 MAIN 输出到负载，请先断开 MAIN BNC 或在接收
端禁用该通道，再执行一次 MAIN ON/OFF 初始化。不要仅依据冷启动、MAIN OFF 状态
下的 SYNC 正占空比判断方波设置值。

设备断电重启期间，旧 VISA ASRL 会话还可能在第一次重连时报
`VI_ERROR_CLOSING_FAILED`。调用 `disconnect_instrument` 清理旧会话后，COM5
和 `ASRL5::INSTR` 可以正常重新发现与连接；该会话释放问题与 SYNC 极性异常相互
独立。

## MCP 工具

- `afg2125_diagnose_setup`：检查 PnP、CDC 驱动、COM、VISA ASRL 和 PyVISA。
- `afg2125_connect`：自动匹配或连接指定 `ASRLx::INSTR`。
- `afg2125_get_settings`：读取当前波形参数。
- `afg2125_set_function`、`afg2125_set_frequency`、
  `afg2125_set_amplitude`、`afg2125_set_offset`：独立配置低层参数。
- `afg2125_set_square_duty`、`afg2125_set_ramp_symmetry`：配置波形细节。
- `afg2125_get_mode_settings`：读取 AM、FM、FSK 和 Sweep 的启用状态。
- `afg2125_configure_am`、`afg2125_configure_fm`、`afg2125_configure_fsk`：
  按手册配置调制源、内部调制波形/频率、深度、偏差、跳频和速率，并回读验证。
- `afg2125_set_am_enabled`、`afg2125_set_fm_enabled`、
  `afg2125_set_fsk_enabled`：关闭或单独启用对应调制模式。
- `afg2125_configure_sweep`：配置起止频率、线性/对数间隔、扫频时间以及
  立即、外部或手动触发源；`afg2125_set_sweep_enabled` 控制模式状态。
- `afg2125_upload_arbitrary_waveform`：下载十进制整数任意波点，不自动选择
  任意波，也不自动开启输出。
- `afg2125_select_arbitrary_waveform`：选择已下载到易失存储器的任意波。
- `afg2125_configure_arbitrary_waveform`：上传并选择任意波、设置频率、校验
  手册规定的 20 MHz 波形速率上限，仍不会自动开启 MAIN 输出。
- `afg2125_set_output`：关闭输出无需确认；开启输出必须传入
  `confirm_enable=true`。
- `afg2125_query_scpi`、`afg2125_write_scpi`：受安全检查保护的通用 SCPI。

## 安全说明

手册中的 `APPLy` 指令会自动开启输出，因此本项目的标准配置工具不使用它。
建议操作顺序是：先保持输出关闭，设置函数、频率、幅度和偏置，检查负载和
接线，最后显式确认后开启输出。驱动会在修改函数、频率、幅度、偏置、占空比、
对称性或选择任意波形前读取输出状态；如果输出已开启，会拒绝修改并要求先关闭。

AM、FM、FSK 和 Sweep 是互斥模式。手册说明启用任一模式时，仪器会自动关闭
其他模式。专用配置工具要求 MAIN 输出先关闭，并在每次写入后查询实际状态；
启用 MAIN 仍需单独调用 `afg2125_set_output(confirm_enable=true)`。

固件 V1.11 能接收 `SOURce1:SWEep:TIME <seconds>`，但手册记录的
`SOURce1:SWEep:TIME?` 及已测试的长短形式、`MINimum/MAXimum` 变体均超时。
因此 Sweep 工具不会伪造时间回读，只返回请求值和兼容性说明；实际扫频周期需
通过输出波形闭环验收。起止频率、间隔、触发源和 Sweep 状态仍进行 SCPI 回读。
此外，V1.11 将手册所写 `IMMediate` 触发源查询为 `INT`，而不是文档示例中的
`IMM`；驱动同时接受这两个等价缩写。

原始 SCPI 工具默认拦截 `APPLy`、`OUTPut`、复位、保存/调取、校准、固件和
文件删除等命令。确需绕过时，必须同时设置服务端环境变量
`AFG2125_ALLOW_UNSAFE=1` 并传入 `confirm_unsafe=true`；正常安装不会开启它。

SYNC 端口与 MAIN 输出相互独立，手册说明即使 MAIN 关闭，默认开启的 SYNC
仍会输出同步 TTL 信号。2026-07-20 在固件 V1.11 实机上测试了手册第 108 页
记录的 `SOURce[1]:OUTPut:SYNC OFF`，包括长短形式、`SOURce1/2`、`OFF/0`、
LF/CR/CRLF、大小写、前导冒号、方括号字面形式和 MAIN 开/关条件。DPO2012B
使用 CH2 MAIN 信号持续触发并对 CH1 实时波形闭环测量，SYNC 始终保持约
2 kHz、5.2 Vpp，状态查询也没有返回。因此当前版本不提供会误报成功的 SYNC
远程开关工具。

GW Instek 官方产品页在 **2026-07-20** 显示 AFG-2100/2000 固件版本为
**2.07**，发布日期为 **2022-05-24**；当前设备为 V1.11。新版固件下载需要
GW Instek 会员登录。现有证据提示可能存在旧固件命令兼容性差异，但尚未通过
升级验证，不能声称 2.07 一定修复 SYNC。固件更新属于高风险操作，不由 MCP
自动执行。需要隔离同步信号时，请断开 SYNC BNC 线或在接收设备侧忽略输入。

官方产品页：<https://www.gwinstek.com/en-US/products/detail/AFG-2100_AFG-2000>
